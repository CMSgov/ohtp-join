# OHTP join site
## Contents

This repository holds the **built static site** for the Office of Health Technology and Products (OHTP) Join page: one HTML page (`index.html`) with its images, fonts, and icons. The source lives in a separate repository; files here are generated, so edit the source and rebuild rather than editing them by hand.

### Publish with GitHub Pages

Settings → Pages → Build and deployment → **Deploy from a branch** → Branch: `main`, folder: `/ (root)`. The site then serves at `https://cmsgov.github.io/ohtp-join/`.
