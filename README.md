# OHTP join site
## Contents

This repository holds the **built static site** for the Office of Health Technology and Products (OHTP) Join page: one HTML page (`index.html`) with its images, fonts, and icons. It is a static export of the brand-compliant redesign (CMS Brand Guide, Sept 2026), built from the OHTP Drupal 11 package. Files here are generated, so edit the source and rebuild rather than editing them by hand. `images/` is kept until the Office of Communications decides on it.

### Publish with GitHub Pages

Settings → Pages → Build and deployment → **Deploy from a branch** → Branch: `main`, folder: `/ (root)`. The site then serves at `https://cmsgov.github.io/ohtp-join/`.
